DETAIL: SimulatedEnergyPod.apply_pq_frame (pod.py:220-231) validates only len(frame)==3 and frame[0]==1, then assigns field-by-field: self._applied_active_w = decode_signed16(frame[1]) executes and mutates state before decode_signed16(frame[2]) can raise. This directly contradicts the module's documented gate ('The transport enforces the write gate, but the device model refuses a malformed frame independently: no caller can half-latch an objective', pod.py:221-225) and the transport's docstring that relies on the device model as defense-in-depth. The production actor path is safe only because SimulatorTransport._validated_pq_frame happens to validate every word first; the pod is exposed directly as the scenario handle runtime.simulators[unit_id], where any test or future consumer gets the half-latch. No test exercises malformed frames against the pod directly.

FIX: Make apply_pq_frame all-or-nothing: validate frame shape and decode all three words into locals (raising on any failure) before assigning any instance state or renewing the lease.
